# 🚐 Motorhome — Pia

Modelo 3D da **pia para motorhome**, desenhada para aproveitar o espaço reduzido de uma
bancada de veículo.

| Arquivo | Descrição |
|---|---|
| `Pia_motorhome.SLDPRT` | Modelo paramétrico (SolidWorks) |
| `Pia_motorhome.STL` | Malha pronta para impressão 3D |

## 🖨️ Como usar

- **`.SLDPRT`** — abrir e editar no SolidWorks.
- **`.STL`** — fatiar e imprimir; ao abrir o arquivo aqui no GitHub aparece o **visualizador 3D**
  na própria página.
